# Live tool surface of https://mcp.riverside.com/mcp — one tool name per line.
#
# WHAT THIS IS
# ------------
# A reviewed snapshot of the tool names the production MCP endpoint serves.
# scripts/validate_tool_names.py checks every tool name in skills/** and
# README.md against this list, so a skill cannot ship a name the server does
# not serve. The packaging validators do not read SKILL.md bodies, which is why
# this gate exists separately from them.
#
# WHY A SNAPSHOT AND NOT A LIVE QUERY
# -----------------------------------
# Calling tools/list requires a user OAuth token, and CI has no way to obtain
# one non-interactively. A live query would therefore either be skipped in CI
# (no gate) or need a long-lived credential in repository secrets. A checked-in
# snapshot is the deliberate tradeoff: it can go stale, but a change to the live
# surface then shows up as a reviewed diff in a pull request instead of as
# silent drift.
#
# The two halves are sourced independently. Namespaces come from the gateway's
# own configuration; tool suffixes come from each backend's tool definitions.
# A rename on either side therefore shows up as a disagreement rather than as
# two matching mistakes.
#
# HOW TO REFRESH
# --------------
# 1. Connect an authorized MCP client to https://mcp.riverside.com/mcp.
# 2. Take the full tools/list result.
# 3. Replace the list below, keeping it sorted.
# 4. Open a PR containing only this file plus the required updates to skills/**
#    and README.md, and say in the description what moved and why. Do not fold a
#    refresh into an unrelated PR.
#
